# つくってためそ メモ帳 Claude版

ブラウザだけで動く、シンプルなテキストエディタです。
YouTubeチャンネル「AIでつくってためそ」の第1回で、Claudeに作ってもらいました。

## ▶ アプリを開く

**https://ai-tsukuttetameso.github.io/tsukutte-tameso-editor-claude/**

インストールやログインは不要です。上のリンクを開くとすぐに使えます。

## できること

- 文字の入力・編集、新規作成、ファイルを開く（.txt）、保存（.txtでダウンロード）
- 元に戻す／やり直し（Ctrl+Z／Ctrl+Y）
- 検索と置換（Ctrl+F／Ctrl+H）
- フォントと文字サイズの変更、右端での折り返しの切り替え
- ステータスバーに行・列と文字数を表示
- 書いた内容をブラウザに自動保存し、次に開いたときに復元

## 安心して使うために

- 書いた内容は、お使いのブラウザの中にだけ保存されます。外部には送信しません。
- 個人情報は扱いません。
